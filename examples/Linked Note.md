# Linked Note

This note exists so that [[Showcase]] has somewhere to link to. Open the backlinks panel (⌥⌘B) here to see the Showcase's three links back to this file, each with the sentence around it.

## Things to try from here

- Rename this file in the sidebar (select it, press Return). The app offers to update the links in the Showcase, and each update is one undo step in its document.
- Type `[[Sho` and finish the name: the link resolves by title or file name, nearest folder first.
- Add a tag such as #linked here and watch the Tags section of the sidebar count it.
- Quick Open (⇧⌘O) and type "show" to jump back.

A link to the daily-note template: [[Daily]] lives in the Templates folder, so Today's Note (⌃⌘N) starts from it.
